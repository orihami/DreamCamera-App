# Dream Camera 0.4.1（泡の装飾を削除）

## 入れ方
- 0.4.0 が入っている → そのまま上書きインストールできます
- 0.3.0 が入っている → 署名が違うので、先にアンインストールしてから入れてください（0.3.0 の自作プリセットは消えます）

## 0.4.0 からの変更
- 泡の装飾を削除（「泡の装飾」スライダーと Aero Bubble プリセットも削除）

## 新しいプリセット（先頭5つ）
| 名前 | 向いているもの |
|---|---|
| Frutiger Aero | 参考動画の Lightroom の数値そのまま |
| Aero Sky | 青空・雲。空を画面の上2/3に |
| Aqua Glass | 水しぶき・グラス・水槽。光のにじみ＋白い四隅 |
| Eco Green | 芝生・葉っぱ＋青空。低い位置から見上げて |
| Vista Aurora | 夜景・ネオン・水槽の青緑の光 |

`色見本-0.4.1.png` は合成画像での比較（左上から：無加工 / Frutiger Aero / Aero Sky / Aqua Glass / Eco Green / Vista Aurora）。

## 撮影のコツ（アプリの機能）
- **画面タップ**：そこにピントと明るさを合わせる。空をタップすると空の青が濃く残る
- **画面長押し**：押している間だけ加工前を表示
- **右上 HDR**：明るい空と影の両方を残す（対応端末のみ。非対応なら通常撮影）
- **右上 ▦**：三分割グリッド
- プリセットごとに「撮影時の露出補正」を保存（Aero 系は −0.3〜−0.7EV で空の白飛びを防ぐ）
- 原本はカメラの JPEG をそのまま保存（再圧縮なし）

## 調整（右下「調整」）
タブ：ライト / カラー / ミキサー / グレーディング / 効果 / 撮影
- ライト：露光量・コントラスト・ハイライト・シャドウ・白レベル・黒レベル・フェード
- カラー：色温度・色かぶり補正・自然な彩度・彩度 など
- ミキサー：8色の丸を選んで 色相・彩度・輝度
- グレーディング：シャドウ／中間調／ハイライトの 色相・彩度・輝度、ブレンド、バランス
- 効果：明瞭度・かすみの除去・光のにじみ・ソフト・周辺光量（マイナスで四隅が白く）・粒子
- 項目名を長押しで初期値に戻る。同じ名前で保存すると上書き。自作プリセットのボタンを長押しで削除

注意：明瞭度はプレビューには出ず、保存画像だけに効きます。Android 12 ではプレビューの色が簡易表示になります（保存画像は正しい色）。
