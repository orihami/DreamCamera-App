# Dream Camera 0.3.0

`DreamCamera-0.3.0-debug.apk` をインストールします。旧版が入っている場合は上書き更新できます。

## 共有から加工する

1. ギャラリーやファイルアプリで写真を開きます。
2. 「共有」から **Dream Camera** を選びます。
3. Dream Cameraで使いたいプリセットを選びます。
4. 左下の「共有写真を加工」を押します。
5. 加工コピーが `Pictures/DreamCamera` に保存されます。元写真は変更しません。

共有起動時、未許可ならカメラ権限は要求しません。通常起動では従来どおり撮影もできます。
