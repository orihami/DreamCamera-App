# Dream Camera 0.2.0

`DreamCamera-0.2.0-debug.apk` をAndroid端末へ送り、開いてインストールします。0.1.0を入れている場合は、そのまま上書き更新できます。

## 撮影

1. 横並びのプリセットを選びます。
2. 画面下中央の大きな丸いシャッターを押します。
3. 原本と加工版が `Pictures/DreamCamera` に2枚保存されます。

## 既存写真の加工

1. 使いたいプリセットを選びます。
2. 左下の「写真」を押し、ギャラリーから画像を選びます。
3. 加工したコピーが `Pictures/DreamCamera` に保存されます。元画像は変更しません。

右下の「調整」から16項目を変更し、名前付きの自作プリセットとして保存できます。

対応OSはAndroid 12以降です。APKは開発用署名です。
