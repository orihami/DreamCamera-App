# Dream Camera 0.1.0

`DreamCamera-0.1.0-debug.apk` をAndroid端末へ送り、開いてインストールします。初回起動時にカメラ権限を許可してください。

## 使い方

1. 画面下部からプリセットを選択します。
2. 「調整・保存」で16項目を変更し、名前を付けて保存できます。
3. 「撮影」を押すと、原本と加工版が `Pictures/DreamCamera` に同時保存されます。

初期プリセットは Natural、Dreamcore、Mallsoft、Liminal Fluorescent、VHS Memory、Y2K Candy、Disposable Flash、Film Gold、Neon Night、Blue Hour、Pastel Haze、Mono Mist の12種類です。

プレビューでは色とぼかしをリアルタイム表示します。粒子・周辺減光・明瞭度などは保存画像に反映されます。

## 注意

- 対応OSはAndroid 12（API 31）以降です。
- APKは開発用署名です。端末によって「提供元不明のアプリ」の許可が必要です。
- 実機カメラでの画質・速度・端末固有動作は未検証です。
