# Dream Camera 0.5.0（画面を一新）

## 入れ方
- 0.4.0 / 0.4.1 が入っている → そのまま上書きインストール
- 0.3.0 が入っている → 先にアンインストールしてから（署名が違うため）

## 画面の見方（上から）
1. **上の段**：⚙ 設定 ／ いま選んでいる色の名前 ／ ⟲ 前後カメラ切替
2. **カメラ画面**：保存される範囲（4:3）だけを表示。写った通りに保存されます
   - タップ＝そこにピントと明るさを合わせる（空をタップすると空が濃くなる）
   - 2本指＝ズーム
   - 長押し＝押している間だけ加工前
3. **色の一覧**：「Aero」「いろいろ」「マイ」で切替。サムネイルは今カメラに映っているものにその色を当てた見本
   - タップで選ぶ。選んでいる色をもう一度タップすると詳しい調整
   - 「マイ」の色は長押しで名前変更・削除
4. **かんたん調整**：「強さ」「明るさ」「暖かさ」を選んでスライダー。↺ で元に戻る。色ごとに覚えています
5. **下の段**：左＝最後に撮った写真（タップで開く）／ シャッター ／ 右＝調整

音量ボタンでもシャッターが切れます（設定で切替可）。

## 詳しい調整
「調整」を押すと、カメラ画面を見ながら下で調整できます。
- 上：✕ やめる ／ 名前 ／ **比較**（押している間だけ加工前）／ 保存
- タブ：ライト・カラー・ミキサー・グレーディング・効果・撮影
- 値を動かした項目には ↺ が出て、押すと初期値に戻る
- 保存すると「マイ」に入ります（同じ名前なら上書き）

## 設定（⚙）
HDR ／ 三分割グリッド ／ 原本も一緒に保存 ／ 音量ボタンでシャッター ／ 写真を選んで加工

## 共有から加工
ギャラリーで写真を共有 → Dream Camera を選ぶ → 色を選んで「この色で加工」
