街角スナップ用の色「スナップ」を追加しました。0.6.0 のバナナ・ダクトテープは取り除きました。

- プリセット一覧に「スナップ」のタブを追加（Aero の隣）。フィルムで撮ったような、少し褪せた色と粒子の6種類
  - Street Portra：昼の街と人に。暖かい肌色・くすんだ緑
  - Night Walk：夜の街灯・看板に。青い影と光のにじみ
  - Superia Green：曇りや日陰に。緑がかった影
  - Old Days：色あせた昔の写真ふう
  - Golden Snap：夕方の金色の光に
  - Mono Street：硬めの白黒
- 長押しでそれぞれの撮り方のコツが出ます
- 「ふつう／バナナを貼る／真ん中に貼る」のボタンはなくなり、アプリも小さくなります（約 38MB → 約 14MB）

入れ方：0.6.0 が入っていればそのまま上書きインストール（設定・マイプリセットは残ります）。
