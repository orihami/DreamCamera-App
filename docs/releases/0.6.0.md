「コメディアン」（バナナをダクトテープで壁に貼った現代アート）ごっこができるようになりました。

- 画面下の一番上に「ふつう／🍌 バナナを貼る／真ん中に貼る」のボタンを追加
- **バナナを貼る**：今写っている所に、テープで留めたバナナを置いて撮れます。指でドラッグして動かし、2本指で大きさを変えます（この間はズームしません）
- **真ん中に貼る**：真ん中に写っている物を自動で見つけて、同じようにダクトテープを貼ります。別の物に貼りたいときはその物をタップ
- 保存されるのは加工版だけ（原本はいつも通りそのまま）。ファイル名の最後に `_BANANA` / `_TAPE` が付きます
- 「写真を選んで加工」でも同じように貼れます
- 「ふつう」を選べば今まで通りのカメラです

入れ方：0.5.x が入っていればそのまま上書きインストール。
