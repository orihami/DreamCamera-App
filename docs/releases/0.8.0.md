「PRO」ボタンで、普通のカメラアプリのプロモードのように手動で撮れるようになりました。

- 画面上の「PRO」を押すと、下に AF・WB・シャッター・ISO・露出・ズームのボタンが並びます
- ボタンを押すとスライダーが出て手動に。左の「A」を押すとオートに戻ります
  - AF：ピントの位置（左が近く、右が ∞）
  - WB：電球・蛍光灯・晴れ・曇り・日陰
  - シャッター：1/8000〜1秒（機種が対応する範囲）
  - ISO：50〜6400（機種が対応する範囲）
  - 露出：＋−の補正（シャッターか ISO を手動にすると使えません）
  - ズーム：2本指でも変えられます
- オートの時は、今カメラが選んでいるシャッター速度と ISO が「A 1/45」のように出ます
- 「PRO」をもう一度押すと全部オートに戻り、いつもの「強さ・明るさ・暖かさ」に戻ります
- PRO 中は HDR を使いません。機種が手動に対応していない項目は「非対応」と出ます

入れ方：いつものリンクから落として上書きインストール（設定・マイプリセットは残ります）。
