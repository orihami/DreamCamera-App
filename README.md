# Dream Camera

Android 12以降向けのプリセットカメラ。撮影1回で原本と加工版を `Pictures/DreamCamera` に保存します。
0.4.0 から Frutiger Aero（青空・緑・水・ガラスの2000年代後半の雰囲気）向けに強化。

- 組み込みプリセット23種（Frutiger Aero 系5種＋スナップ6種＋従来12種）
- Lightroom と同じ並びの調整：ライト（露光量・コントラスト・ハイライト・シャドウ・白レベル・黒レベル）、
  カラー（色温度・色かぶり・自然な彩度・彩度）、カラーミキサー8色×色相/彩度/輝度、
  カラーグレーディング（シャドウ/中間調/ハイライト・ブレンド・バランス）、効果（明瞭度・かすみ・光のにじみ・ソフト・周辺光量・粒子）
- 色は 3D LUT 1本で計算し、Android 13 以降はライブプレビューにも同じ色を GPU で適用
- 画面：選んだ色の見本がカメラ映像のサムネイルで並ぶ（Aero / スナップ / いろいろ / マイ）、強さ・明るさ・暖かさをメイン画面で調整
- 撮影：プリセットごとの露出補正、タップでピント＋測光、HDR（対応端末）、2本指ズーム、前後カメラ切替、音量ボタンでシャッター、三分割グリッド、画面長押しで加工前と比較
- 原本はカメラの JPEG をそのまま保存（再圧縮なし・Exif 付き）
- 共有メニュー／写真ボタンから既存写真も加工

初回起動時にカメラ権限を許可してください。

## ビルド

`./gradlew assembleDebug`。リリース方法は CLAUDE.md を参照。
